# 매거진 커버 메이커

사진을 끌어다 놓으면 바로 매거진 표지가 되는 도구입니다. 설치할 것도, 로그인할 것도 없습니다.
**HTML 파일 하나**로 되어 있고 모든 처리가 브라우저 안에서 끝납니다.

**→ [바로 써보기 (PC)](https://musicits.github.io/magazine-cover-maker/)**

**→ [휴대폰으로 쓰기 (모바일)](https://musicits.github.io/magazine-cover-maker/m/)**

---

## 무엇을 할 수 있나

- **매거진 25종 조판 프리셋** — 제호 서체·자간·크기뿐 아니라, 그 잡지가 실제로 문구를 놓는 자리까지 예시로 채워집니다
- **라이트룸식 색보정** — 노출·대비·밝은 영역·어두운 영역·흰색·검정 / 색온도·색조·생동감·채도 / 톤 커브(RGB·R·G·B) + 히스토그램
- **필름 룩 필터 9종** — 세기 0~100% 조절
- **로고 앞뒤 겹치기** — 모델이 제호 앞으로 나오게
- **여러 장 한 번에** — 사진을 여러 장 넣고 같은 디자인으로 일괄 저장

## 사진은 어디로도 올라가지 않습니다

넣으신 사진과 문구는 **브라우저 밖으로 나가지 않습니다.** 서버로 전송하는 코드가 없습니다.
설정은 브라우저 로컬 저장소에만 남고, 사진은 저장조차 하지 않습니다.

---

## 쓰는 법

1. 왼쪽 점선 상자에 사진을 끌어다 놓습니다 (여러 장 가능)
2. **3. 제호**에서 매거진을 고릅니다
3. 문구를 내 것으로 바꿉니다 — 줄 앞에 `*`를 붙이면 그 줄만 강조색
4. **14. 내보내기**에서 PNG로 저장

미리보기에서 **드래그**하면 사진 위치, **휠**은 확대/축소입니다.
도구 안 오른쪽 위 **?** 버튼에 더 자세한 설명이 있습니다.

### 제호에 쓸 수 있는 표기

| 표기 | 결과 | 예 |
|---|---|---|
| `*...*` | 그 부분만 기울임 | `HIGH *CUT*` |
| `^...^` | 위첨자 | `1^st^ Look` |

## 휴대폰판 (`m/`)

주소 뒤에 `m/` 만 붙이면 됩니다 — <https://musicits.github.io/magazine-cover-maker/m/>

사진 편집 앱과 같은 짜임새입니다. **위는 미리보기, 아래는 도구바.**

- 맨 아래 줄이 **단계** 입니다 — **사진**(고르기) → **커버**(조판) → **보정**(빛·색) → **내보내기**(저장)
- 그 위 줄은 지금 단계의 **항목**. 누르면 그 항목의 조절판만 올라오고, 한 번 더 누르면 접혀서 미리보기가 다시 커집니다
- 사진이 두 장 이상이면 **작은 사진 줄(필름스트립)** 로 넘깁니다. 커버 설정은 그대로 유지됩니다
- 사진 넣기는 **사진 앨범 · 카메라 · 파일/구글 드라이브** 중에서 고를 수 있습니다
  (‘파일·드라이브’ 는 휴대폰 파일 앱을 열어 구글 드라이브·원드라이브·다운로드 폴더까지 닿습니다)
- 미리보기를 **한 손가락**으로 끌면 사진 이동, **두 손가락**을 벌리면 확대·축소
- 미리보기의 제호·문구를 **톡** 치면 그 항목의 조절판이 바로 열립니다
- 오른쪽 위 **저장**(파일로 내려받기) · **공유**(사진 앨범·메신저로 바로 보내기)

기능·조판·보정은 PC 판과 똑같습니다. 설정은 PC 판과 따로 저장됩니다.

### 휴대폰판은 어떻게 만들어지나

`m/index.html` 은 **PC 판에서 그리기 엔진과 메뉴를 그대로 떼어 와** 만든 파일입니다.
PC 판(`index.html`)은 읽기만 하고 절대 고치지 않습니다.

PC 판을 손본 뒤에는 아래 한 줄로 휴대폰판을 다시 만들면 됩니다.

```bash
python3 m/_build/build.py
```

휴대폰 화면 전용 부분(CSS·손가락 조작·하단 시트)은 `m/_build/` 안의 조각 파일들에 있습니다.
`m/index.html` 을 직접 고치면 다시 만들 때 사라지니, 고칠 일은 `m/_build/` 쪽에 하세요.

## 직접 돌리기

```bash
git clone https://github.com/musicits/magazine-cover-maker.git
```

`index.html`을 브라우저로 열면 끝입니다. 빌드 과정이 없습니다.
서체는 Google Fonts에서 받아오므로 처음 열 때 인터넷이 필요합니다.

**권장 환경** Chrome / Edge / Safari 최신 버전 (Canvas 2D와 웹폰트 로딩 API를 씁니다)
